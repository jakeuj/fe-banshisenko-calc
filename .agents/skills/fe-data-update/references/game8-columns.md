# game8 計算器 JSON 欄位對照

來源：`https://assets.game8.jp/tools/script_template/fe_banshisenko_ikusei_sim.json`
結構：陣列，每個元素 `{ id, category_db_id, db_data: [row...] }`；每列有 `title`（日文名，當作 id 使用）、`url`、`col_1`…`col_60`、`l_col_1`…。

數值欄一律依這個順序（本專案的 `STATS` 也是這個順序）：

`HP, 力, 魔力, 速さ, 技, 守備, 魔防, 幸運, 魅力` → 鍵 `hp str mag spd dex def res lck cha`

> 注意：game8 網頁上的計算器小工具顯示順序是「技、速さ」，但 JSON 欄位是「速さ、技」。以 JSON 為準。

## 23026 角色

| 欄位 | 意義 |
|---|---|
| `col_1` | 是否在計算器顯示（◯）|
| `col_2` | 所屬陣營（日文，對應 `FACTION_ZH`）|
| `col_3` | 性別（男/女；救世主為空）|
| `col_10` | 個人技能名 |
| `col_12` / `col_14` | 得意 / 苦手技能（`:` 分隔）|
| `col_20`–`col_28` | 個人成長率 |
| `col_29` | 成長率合計 |
| `col_45`–`col_49` | 推薦職業：初級 / 中級 / 上級 / 最上級 / 神將 |
| `col_50` | 意義未確認（主角名列表），未使用 |
| `col_53` | 評價（S/A/B/C）|
| `col_57` | 排序編號 |

沒有 `col_20` 的列（NPC、救世主男/女）會被略過。

| `col_42`–`col_47` | 必修技能與等級（成對）|

## 錨點檢查（懷疑欄位被 game8 改動時）

用下面這些已知值確認欄位沒有位移。任何一個對不上，就先修 `build-data.mjs` 的欄位讀取，不要改測試的期望值：

- レダ 個人成長率 = `[40, 35, 35, 65, 50, 30, 35, 25, 55]`（速度 65、技巧 50）
- 戦車兵 原始職業成長率 速 `-5`、技 `+25`（技巧會被 CORRECTIONS 改成 15）
- ソフィア 加入資料 = 呪い師 Lv8，顯示值 `[25, 6, 15, 6, 9, 6, 12, 7, 7]`
- `node tools/test-calc.mjs` 的「ソフィア推薦路線 = game8 計算器輸出」要通過（合計 134 / 194 / 241 / 463）

快速檢視某列所有非空欄位：

```bash
node -e "const j=require('./tools/raw/game8.json');const r=j.find(t=>t.id===23026).db_data.find(x=>x.title==='ソフィア');for(const [k,v] of Object.entries(r)) if(v!==''&&v!==null) console.log(k, String(v).slice(0,80))"
```
